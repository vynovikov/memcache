# memcache
memcache - это крохотный кэш с поддержкой функционала шардирования, LRU и TTL. Кэш используется как сторонняя библиотека напрямую в коде Go. Разработан как высокопроизводительный, low-latency инструмент

Кэш решает несколько задач:
* уменьшение нагрузки на процессор, вызванное [**lock contention**](#lock_contention)
* вытеснение элемента, с которым работа не проводилась дольше всех - [**Least recently used**](#lru)
* время жизни каждой записи, по истечении которой она удаляется из кэша - [**Time to live**](#ttl)

<a id="lock_contention"></a>

### Lock contention

При одновременном доступе на запись к кэшу нескольких горутин для безопасности внутренних структур и избежания гонок данных требуется синхронизация мьютексом. При этом если мьютекс один на весь кэш, а обращений много, то большая часть времени уходит просто на ожидание его переключения. Эта проблема решена за счет шардирования. Кэш представляет собой кластер шардов с индивидуальным мьютексом.

#### Вычисление индекса шарда

Определение шарда для пары ключ-значение всегда однозначно и производится эффективно благодаря двум решениям: количеству шардов и хеш функции.

**Количество шардов** - степень двойки. Благодаря этому для вычисления индекса шарда мы можем использовать битовую арифметику, максимально удобную для CPU

**Хэш-функция** - максимально быстро высчитывает некоторое число от значения ключа со следующами свойствами:
- хэш от одного и того же ключа всегда одинаковый
- хэши от двух похожих ключей отличаются друг от друга как и от сильно различных

Определение нужного шарда представляет всего одну операцию: двоичное представление хэша побитово умножить на двоичное представление от числа шардов минус 1

```
111001100001101010011011010100101 (хэш)
*
000000000000000000000000000011111 (количество шардов минус 1)
=
00101 (то есть 9 в десятичном представлении)
```
получим последние биты хэша. Их десятичное представление и определяет индекс шарда.


<a id="lru"></a>

### LRU

Вытеснение элемента, к которому обращались наиболее давно производится благодаря выбору удобной структуры данных - двусвязный список (doubly linked list). Это линейная цепочка узлов. Каждый узел хранит ключ и два указателя: на предыдущий и последующий узлы. Самый первый узел - голова списка **HEAD** имеет указателем на предыдущий элемент в значении nil. Соответственно,  у самого последнего узла **TAIL**  указатель на последующий элемент так же равен nil

- при обращении к нужному элементы мы просто меняем указатели соответствующего узла и его соседей.
- при превышении максимального числа узлов мы замыкаем указатели его соседей друг на друга

Эти операции производятся за единичное время
